# wikipedia2obsidian

Wikipedia, converted into Obsidian-friendly Markdown.

## Contents


| Pack                         | Source (Kiwix / openZIM)        | Notes                               | Size                         |
| ---------------------------- | ------------------------------- | ----------------------------------- | ---------------------------- |
| `wikipedia_on_computers.zip` | `wikipedia_en_computer` (nopic) | All Wikipedia articles on computers |230.3MB (721.2MB uncompressed)|


Each article is one `.md` file. Internal links use Obsidian wikilinks; citations jump to reference blocks; Use **Reading view** for the best experience.
